**relvista** 1.0 is out. It draws entity-relationship diagrams from
[DBML](https://dbml.dbdiagram.io/docs/), the schema language dbdiagram.io uses, and it is open
source. There are three ways to use it: a Docusaurus plugin for your documentation, an editor that
runs in your browser, and the React and TypeScript libraries both are built on. The plugin and the
libraries are MIT licensed; the editor is AGPL-3.0-or-later.

## Diagrams in your Docusaurus docs

```bash npm2yarn
npm install @relvista/docusaurus-plugin
```

```ts title="docusaurus.config.ts"
export default {
  plugins: ['@relvista/docusaurus-plugin'],
};
```

Every ` ```dbml ` code fence becomes an interactive diagram:

```dbml height=320 title="Announcement"
Table users {
  id integer [pk]
  email varchar [unique]
}

Table posts {
  id integer [pk]
  author_id integer [ref: > users.id]
  title varchar
}

Table comments {
  id integer [pk]
  post_id integer [ref: > posts.id]
  author_id integer [ref: > users.id]
}
```

The plugin only adds diagrams: your theme, colours, fonts and custom CSS stay as they are, and the
diagrams take your site's colours and dark mode. Each diagram is laid out at build time and written
into the page as an SVG, so it shows without JavaScript, in print and to search engines; the
interactive viewer takes over in the browser. From the toolbar you can search tables and columns,
find the relationship path between two tables, switch between names, keys and all columns, focus
on the tables related to one, export SVG, PNG or a multi-page PDF, print, and copy a link that
opens the diagram in exactly that state. [Schema diffs](/docs/diff) show what changed between two
versions of a schema. Start with [Getting started](/docs/getting-started).

## An editor for your `.dbml` files

The [relvista editor](pathname:///editor/) is a static web app: open a `.dbml` file or a whole
folder, edit it with completion, diagnostics and quick fixes, and arrange the diagram next to it.
There is no account and no server, and your files stay on your disk. Saving writes back to the
same file (in Chromium browsers; elsewhere it downloads). A file you open and save without editing comes back byte for byte, comments and
formatting included, and table positions go to a small `schema.dbml.layout.json` file next to it,
never into your DBML. See the [editor guide](/docs/editor).

## Libraries

`@relvista/core` compiles DBML into a diagram model, reads and writes layout files, lays diagrams
out automatically (ELK and dagre), and searches and diffs schemas, in Node or the browser.
`@relvista/renderer` draws diagrams in React 18 or 19: a static SVG renderer, the interactive
viewer and an editable canvas, with SVG, PNG and PDF export. Both are described in the
[API reference](/docs/reference).

## What 1.0 promises

- **Your DBML stays dbdiagram.io DBML.** relvista parses it with
  [@dbml/parse](https://www.npmjs.com/package/@dbml/parse), Holistics' own parser, pinned to an
  exact version. A file valid on dbdiagram.io opens unchanged and saves back unchanged unless you
  edit it.
- **Semantic versioning.** The three packages are released together with one version number. The
  public API, the `layout-1` layout file format and the compatibility promise above change only in
  a new major version ([details](/docs/reference)).
- **Requirements.** Node 20 or later; React 18 or 19; Docusaurus 3.6 or later with the classic
  theme (React 19 needs Docusaurus 3.7 or later).
